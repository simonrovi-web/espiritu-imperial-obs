# Espíritu Imperial: sistema visual

- **Dirección:** premiación de gala televisiva, ejecutada al nivel de un paquete gráfico de TV (elección del cliente).
- **Color:** escenario azul marino (#0A2F5E → #063661 → #041F3D) con haces de luz suaves y una luz cálida roja desde abajo. El rojo Imperial (#ED2939, #C8102E para texto blanco encima) se usa solo como señal: reglas bajo títulos, la etiqueta de sucursal, EN VIVO y bordes de lo que está al aire. El blanco se usa para nombres y títulos, y #AFC0D6 para el texto secundario.
- **Tipografía:** Roboto Condensed 900 en mayúsculas para nombres y títulos; Roboto Condensed 400 espaciado ("ESPÍRITU") en el sello del evento; Roboto 400/500 para cargos, motivos y datos.
- **Composición:** un nombre por pantalla y grande. La sucursal antecede al destacado; el tablero muestra las sucursales que vienen como "Por revelar".
- **Movimiento:** entradas con desenfoque que se asientan (ease-out exponencial) y un solo brillo por título. Las transiciones tapan la pantalla a la mitad (Telón, Destello, Franjas, Marco).
- **Logo:** solo la versión web de 300 px, nunca ampliada; el sello tipográfico "ESPÍRITU IMPERIAL" cubre los tamaños grandes.
